Automatically scrape web pages and create WooCommerce products with a click.

== Description ==

AJDWP Auto Product Maker is a WordPress plugin that helps WooCommerce store owners automate product creation by scraping data from provided URLs. You can input links to pages, preview the extracted data (title, price, image, etc.), and auto-create WooCommerce products.

Perfect for bulk product management, marketplace automation, and simplifying store updates.

**Key Features:**
* Add URLs manually or via bulk upload
* Scrape product title, price, description, and images
* Automatically create WooCommerce products
* Lightweight admin UI
* Custom field mapping (coming soon)

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ajdwp-auto-product-maker` directory, or install via the WordPress admin panel.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to `WooCommerce > Auto Product Maker` to start scraping and creating products.

== Plugin Specs ==

1. Admin panel for entering product URLs.
2. Preview of scraped product data before submission.
3. List of auto-created WooCommerce products.
